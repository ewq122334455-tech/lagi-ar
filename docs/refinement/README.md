## 2. 수정한 것
- **브랜드:** 제목·설명·OG(`LAGI — LAGI in AGAIN`, 새 브랜드 정의, og-image.jpg 1200×630 추가), 파비콘 경로, About·푸터·Discover·Why·역할 문구를 새 정의("디자인과 완성도, 소재의 새로운 가능성을 발견하고 제품을 선별해 소개하는 큐레이션 브랜드. 제품은 제작사가 만들고 라기는 발견·선별·소개·연결")로 통일. `/classic`은 홈으로 연결(코드는 `src/pages`에 보존), 404를 새 디자인으로.
- **타이포:** 화면 폭에 따라 부드럽게 바뀌는 `clamp()` 크기(디스플레이 48→92px, 본문 14→15px 등), 회색 글자 #626262(흰 배경 5.9:1)로 대비 확보, 어두운 배경 글자 80% 이상.
- **상품 상세:** 첫 화면 = 사진(왼쪽) + 이름·가격·수량·구매 버튼(오른쪽, 따라옴). 사진은 원본의 1.15배 이상 키우지 않음. 흐린 확대 컷 제거, 사진이 여러 장일 때만 갤러리 표시. 순서: 사진 → 이름·가격·구매 → (사진) → 소재와 제작 → 이 제품을 고른 이유(네 가지 기준) → AI 이미지 합성 → 구매 → 다른 제품 → 다음 제품. 섹션 이름 한국어 우선, 둥근 회색 카드 제거.
- **WHY LAGI:** 마지막에 "네 가지 기준을 모두 통과한 제품" 8개(실제 제품 사진·가격, 상세 연결) 추가.
- **모바일:** 헤더 64→56px, 로고 44→36px, 터치 영역 40px 이상(화면이 터치일 때), BRAND FILM 버튼을 오른쪽 위로, 푸터는 링크 아래에 엠블럼(겹침 해소).
- **성능:** About의 three.js를 리본에서만 불러옴(About 467KB → 3.9KB + 리본 464KB 별도), Jost 폰트 제거, 사용하지 않는 영문 초안 파일 삭제.
