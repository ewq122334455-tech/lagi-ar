# 법적 고지 준비 상태 (2026-11-10)

사이트에는 아직 법적 고지가 **하나도 노출되지 않습니다.** 내용을 채울 화면 구조만 준비해 두었습니다.

- 내용 파일: `src/content/legal.ts`
- 화면 동작
  - 푸터의 사업자 정보 블록과 `/privacy`, `/terms` 페이지는 해당 값이 채워질 때만 나타납니다.
  - 가입 동의 문구 옆 링크도 마찬가지입니다.
  - 값이 `null`이면 아무것도 렌더링하지 않습니다.
- 예시 문구나 빈 틀은 넣지 않았습니다. 채운 내용은 그대로 실제 고지로 게시되므로 **사실 정보와 법률 검토를 거친 문안만** 넣어 주세요.

## 1. 채워야 할 값

| 필드 (`BUSINESS`) | 내용 | 근거 (확인 수준) |
|---|---|---|
| `companyName` | 상호 | 전자상거래법 제10조, 시행규칙 제7조: 초기 화면 표시 (공정위 심결문 인용, 높음) |
| `representative` | 대표자 성명 | 위와 같음 |
| `address` | 영업소 주소 (소비자 불만 처리 주소 포함) | 위와 같음 |
| `phone`, `email` | 전화번호, 전자우편주소 | 위와 같음 |
| `businessNumber` | 사업자등록번호 | 위와 같음 |
| `hostingProvider` | 호스팅서비스 제공자 상호 | 제10조 제1항 제6호 + 시행령 (심결 사례, 높음). 현재 사이트는 GitHub Pages, API는 Cloudflare. 어떻게 표기할지는 확인이 필요합니다 |
| `mailOrderNumber` | 통신판매업 신고번호 | 제13조 관련 심결(미표시를 위반으로 판단). **적용 범위 확인 필요** |

**문서**
- `PRIVACY_POLICY`(개인정보처리방침)
  - 개인정보 보호법 제30조에 따라 **지금 의무**입니다. 이미 가입(이름·이메일), 주문서(휴대폰·주소), AI 합성(얼굴 사진)으로 개인정보를 수집하고 있습니다.
  - 개인정보보호위원회 「개인정보 처리방침 작성지침」 2025년 4월 개정본의 항목을 따르세요.
  - 처리 위탁과 국외 이전 대상(Google Gemini, Cloudflare, Decart, Toss Payments, Kakao 우편번호)을 적어야 할 것으로 판단되나, **세부 요건은 확인 필요**합니다.
- `TERMS`(이용약관): 제10조 제1항 제5호. 초기 화면에서 링크로 연결할 수 있습니다.

**사업자정보 확인 링크**
- 푸터에 공정위 사업자정보 공개 페이지 링크(`ftc.go.kr/bizCommPop.do?wrkr_no=사업자번호`)를 둡니다.
- 2020년 시정명령 사례에서 이 연결을 하지 않은 것이 지적되었습니다. **링크 주소 형식은 게시 전에 직접 확인**해 주세요.

## 2. 회원 탈퇴 (구현 완료, 꺼져 있음)

- `POST /auth/delete`와 계정 화면의 "회원 탈퇴"가 준비되어 있습니다(본인 세션 + 비밀번호 + "탈퇴" 입력).
- Worker 설정 `WITHDRAW_REVIEW_POLICY`가 비어 있으면 탈퇴 요청에 "준비 중, 인스타그램 DM으로 요청"이라고 답합니다.
- 결정할 것: 탈퇴 회원의 구매평을 어떻게 할지
  - `keep-anonymous`: 이름과 이메일 없이 남김
  - `delete`: 삭제
- 결제 완료 주문 기록은 탈퇴해도 지우지 않고 회원 연결만 끊습니다. 법정 보존 기간은 **확인 필요**합니다.

## 3. 확인하지 못한 것
- 국가법령정보센터(law.go.kr) 원문. 작업 환경의 네트워크 정책으로 접속하지 못해, 공정위 심결 발췌와 2차 자료로 확인했습니다.
- 과태료 금액
- 통신판매업 신고 의무의 적용 범위(현재 결제는 스마트스토어에서 이루어짐)
- 주문 기록 보존 기간
