# LAGI 웹사이트 최종본 — 먼저 읽기

LAGI(라기) 웹사이트의 최종본입니다. 이 폴더 하나로 **다른 컴퓨터에서 바로 열고**, 필요하면 **코드를 받아 작업**할 수 있습니다.

## 폴더 구성

| 폴더·파일 | 내용 |
|---|---|
| `LAGI 시연 안내 (먼저 여세요).html` | **시연할 때 먼저 여는 안내 페이지.** 바로가기 버튼, 시연 순서, 시연 전 확인 사항 |
| `00_먼저읽기.md` | 지금 읽는 문서 |
| `01_기능_설명.md` | 사이트에 어떤 기능이 있는지 |
| `02_작성방식_가이드.md` | 사이트가 어떻게 만들어져 있고, 어떻게 고치고 추가하는지 |
| `사이트_오프라인/` | **인터넷 없이 열리는 사이트.** 안의 `index.html`을 더블클릭 |
| `영상/` | AI 시연 영상(4K, 미리보기), 기술 설명서 PDF |
| `소스코드/` | 전체 소스(`LAGI_소스코드.zip`). 작업하려면 이것을 풉니다 |
| `LAGI 온라인 사이트 열기.webloc` / `.url` | 실제 운영 중인 사이트로 바로 이동 (맥 / 윈도우) |

## 1. 그냥 열어서 보기 (인터넷 필요 없음)

1. `사이트_오프라인` 폴더를 연다.
2. `index.html`을 더블클릭한다. (Chrome 권장. Edge, Safari도 열립니다.)
3. 처음 화면에서 영상이 나오면 화면을 한 번 누르면 사이트로 들어갑니다.

- 서버, 설치, 호스팅 주소가 **필요 없습니다.** 폴더를 USB, AirDrop, 메일로 옮겨도 그대로 열립니다.
- 폴더 이름과 위치는 아무 곳이어도 됩니다. 단, **폴더 안의 파일 배치는 바꾸지 마세요.**
- 확인한 것: 인터넷을 완전히 끊은 상태에서 모든 페이지가 열리고, 인터넷 요청이 0건이었습니다. (Chromium 기준으로 검사했습니다. Safari와 Firefox는 직접 확인하지 못했습니다.)

## 2. 오프라인에서 되는 것 / 안 되는 것

| 기능 | 오프라인 폴더 | 온라인 사이트 |
|---|---|---|
| 홈, 제품 목록, 제품 상세, WHY LAGI, REVIEW, 브랜드 필름 | 됩니다 | 됩니다 |
| 제품 21점 전체, 사진, 가격, 사이즈표, 검색 | 됩니다 | 됩니다 |
| 장바구니 담기 | 됩니다 | 됩니다 |
| AGAIN **사진 합성**(AI) | 화면은 열리지만 합성은 **안 됩니다** | 됩니다 |
| AGAIN **AI 영상**(실시간 AI) | 화면은 열리지만 시작은 **안 됩니다** | 됩니다 |
| 회원가입·로그인, 실제 구매평 | **안 됩니다** | 됩니다 |
| 브랜드 글꼴(Posterama) | 비슷한 기본 글꼴로 보입니다 | 정식 글꼴 |

**AI 기능은 인터넷으로 운영 사이트를 열어야 합니다.** 이유: AI를 돌리는 서버(Cloudflare Worker)가 *지정된 사이트 주소에서 온 요청만* 받도록 잠겨 있어서(비용과 악용 방지), 폴더에서 파일로 연 화면의 요청은 거절됩니다. 영상은 `영상/` 폴더의 시연 영상으로 대신 볼 수 있습니다.

운영 사이트: https://ewq122334455-tech.github.io/lagi-ar/

## 3. 코드를 받아 작업하기

필요한 것: **Node.js 20 이상**(https://nodejs.org 에서 LTS 설치), 터미널.

```bash
cd 소스코드/lagi-ar          # LAGI_소스코드.zip을 푼 폴더
npm install                  # 처음 한 번 (인터넷 필요)
npm run dev                  # http://localhost:5173 에서 열림, 고치면 바로 반영
npm run build                # 운영용 빌드 (dist/)
npm run build:offline        # 이 폴더의 '사이트_오프라인'을 다시 만드는 명령 (dist-offline/)
```

자세한 구조와 규칙은 `02_작성방식_가이드.md`를 보세요.

## 4. 꼭 지켜야 할 약속 (비용·보안)

- **API 키를 파일에 쓰지 마세요.** 채팅, 코드, 문서, 메일 어디에도 키를 적지 않습니다. 이 폴더에는 키가 들어 있지 않습니다.
- **AI 기능은 실행할 때마다 돈이 듭니다.** 실시간 AI 영상(Decart)은 약 0.02달러/초, 사진 합성(Gemini)은 한 장당 과금입니다. 시험은 꼭 필요한 만큼만 하고, 시작 전에 책임자 승인을 받으세요.
- 사이트에 **올리는 작업(운영 반영)은 승인을 받고 하세요.** 방법은 `02_작성방식_가이드.md`의 "운영에 반영하기"를 보세요.
- 제품 정보 중 **"예시 정보 · 확인 전"** 표시가 붙은 값(가격, 소재, 사이즈, 제조국 등)은 실제 값이 아니라 임시로 채운 예시입니다. 판매 전에 반드시 실제 정보로 바꿔야 합니다.
- 리뷰 페이지의 후기 20개도 화면 구성을 위한 **예시**입니다(페이지에 안내 문구가 있습니다). 실제 후기처럼 쓰면 안 됩니다.

## 5. 지금 상태 (요약)

- 제품 21점: 가방·소품 8점, 의류 13점(상의 3, 모자 2, 아우터 2, 바지 6). 의류와 바지는 LAGI 로고 제품으로 교체됨.
- 판매는 멈춘 상태입니다. "바로 구매"는 네이버 스마트스토어로 연결되고, 사이트 자체 결제는 꺼져 있습니다.
- 이름, 가격, 소개 글(의류·바지)은 제가 사진을 보고 임의로 만든 값입니다. 바꾸고 싶으면 `public/products/<제품>/product.json`을 고치면 됩니다.
- 영상은 2026-11-20에 만든 것이라 **그때의 제품(이전 의류)이 나옵니다.** 사이트 기능은 같습니다.
