# LAGI 디자인 시스템 (v3)

레퍼런스 측정값(02-reference-analysis.md)을 기준으로, LAGI에 맞게 바꾼 부분은 이유를 적었다.
코드: `src/v3/tokens.css`

## 컬러
| 토큰 | 값 | 근거 |
|---|---|---|
| `--c-white` | #FFFFFF | 레퍼런스 콘텐츠 배경 [확인]. 기존 LAGI 토큰 `paper`와 같음 |
| `--c-gray` | #F1F1F1 | 레퍼런스 홈 배경 [확인: 픽셀]. LAGI에 공식 Light Gray 코드가 없어 측정값 사용 — **공식 값이 정해지면 교체** |
| `--c-ink` | #0F0F0F | 레퍼런스 푸터 [확인: 픽셀]. 기존 LAGI `ink` #151515와 사실상 같은 계열 |
| `--c-blue` | #1D5198 | LAGI 공식 엠블럼 파일의 색 |
| `--c-line` | #000000 | 레퍼런스 구분선 [확인] |

포인트 컬러는 LAGI Blue 하나. 그라디언트·그림자 없음.

## 타이포그래피
글꼴: **Pretendard** (브리프 지정). 레퍼런스 Suisse Intl은 유료 라이선스라 쓰지 않음. 같은 그로테스크 계열이고 한글을 함께 지원.
한글은 라틴보다 글자 면적이 커서, 레퍼런스 자간(−0.05em)을 그대로 쓰면 붙어 보임 → 한글 기준 −0.03em으로 조정.

|---|---|---|---|---|---|---|
| Display | 80 | 72 | 56 | 700 | 0.95 (레퍼런스 0.87 → 한글 받침 겹침 방지로 조정) | −0.04em |
| H1 | 64 | 48 | 32 | 600 | 1.2 | −0.03em |
| H2 | 56 | 40 | 40 | 700 | 1.0 | −0.03em |
| H3 | 32 | 28 | 24 | 700 | 1.0 | −0.03em |

## 모션
레퍼런스 수치는 측정하지 못했으므로(02 문서 7절) 아래 값은 **LAGI가 정한 값**이다.
| 토큰 | 값 |
|---|---|
| fast | 160ms |
| standard | 420ms |
| slow | 900ms |
| ease-out | cubic-bezier(.2,.7,.2,1) |
| ease-in-out | cubic-bezier(.65,0,.35,1) |
| 갤러리 추종 | 매 프레임 목표값의 9%씩 따라감(관성), 입력이 멈추고 160ms 뒤 가장 가까운 제품에 정렬 |

`prefers-reduced-motion`: 관성·자동 정렬·등장 애니메이션 끔, 갤러리는 버튼/키보드로 한 칸씩 이동.

## LAGI 갤러리 — 레퍼런스와 다른 점
| 레퍼런스 | LAGI | 이유 |
|---|---|---|
| WebGL(OGL) | DOM `<a><img>` + CSS transform | 제품마다 실제 링크·키보드 포커스·스크린리더 접근 유지, 3D 엔진 불필요 |
| 평면을 3D 원근으로 기울임 | 기울임 없이 이동·균일 축소·약한 Z 회전만 | “제품 형태 왜곡 금지” — 원근 기울임은 사진을 사다리꼴로 찌그러뜨림 |
| 크롭 없음 | **CROP**: 뒤로 갈수록 LAGI 모티프 모양으로 잘려 보이고, 앞으로 올수록 원본이 다 드러남 | 브랜드 그래픽 개념 POINT·CROP·FREEFORM MARK 반영 |
| 사슬 경로(측정 불가) | L·Λ·G·I 모티프 리듬을 단순화한 곡선(좌하→우상) | 레퍼런스 흐름 방향은 따르되 경로 형태는 LAGI 고유 |
