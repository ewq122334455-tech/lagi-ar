조사 방법: Playwright(Chromium)로 실제 접속, `getComputedStyle`·`getBoundingClientRect`로 값 추출, 화면 캡처. 2026-10-23.
표기: **[확인]** = 브라우저에서 측정한 값 / **[추정]** = 캡처를 보고 판단한 값(측정 아님).

## 2. 기술 [확인]
- Framer로 제작. 홈 갤러리 스크립트로 `esm.sh/ogl`(WebGL 라이브러리)과 `esm.sh/gsap` 로드.
- 홈 갤러리 이미지는 DOM `<img>`가 아니라 canvas에 그려짐(측정 시 `<img>` 0개).
- 홈 워드마크: 흰색 `h1`을 감싼 요소에 `mix-blend-mode: difference`, `z-index: 2`.

## 5. 홈 갤러리
| 항목 | 내용 | 근거 |

| 배열 | 이미지 평면들이 좌하단(가깝고 큼)에서 우상단(멀고 작음)으로 이어지는 하나의 곡선 사슬 | [확인: 캡처] |
| 회전 | 각 평면이 원근 속에서 비스듬히 기울어 보임(Y축 회전 + 약간의 Z축 회전) | [추정: 캡처] |
