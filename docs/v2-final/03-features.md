# 03. 기능 — 유지 · 제거 · 새로 만든 것

## 유지 · 이식
| 기능 | 새 위치 | 상태 |
|---|---|---|
| 제품 데이터(실판매 8개) | 홈 SELECTED, /discover, /product/:id | 확인된 정보만 표시 |
| 장바구니 | /cart (기존 CartContext 그대로) | 테스트 통과 |
| 스마트스토어 구매 연결 | 상세·주문서 | 공식 스토어 홈으로 연결(상품별 주소 필요) |
| AI 이미지 합성 | /again (옛 주소 /ai-fit/:id, /try-on/:id는 자동 이동) | 아래 참고 |
| 회원가입·로그인 | /login, /signup, /account | 코드 정상. **배포된 Worker가 구버전이라 실제 사이트에서는 재배포 후 작동** |
| 이전 사이트 | /classic | 보존 |

## 제거
개별 제품 3D 뷰어, 회전, GLB 뷰어, 카메라 조작, 핫스팟, 3D 생성 UI, 플레이스홀더 모델, `/exhibition`(3D 전시 → 홈으로 이동), 작업실의 3D·핫스팟 탭, `@react-three/fiber`·`drei`·`three-stdlib`. GLB 10개는 `archive/3d-models/`로 옮겨 보관(배포 제외).

## AI 이미지 합성 (AGAIN EXPERIENCE)
단계: 01 제품 선택 → 02 사진 올리기 / 카메라 촬영 → 03 착용 방식(가방 3가지, 소품 2가지 — Worker가 지원하는 것만) → 04 동의 후 합성 → 05 결과 확인 → 06 저장 · 공유 · 다시.

| 항목 | 구현 |
|---|---|
| 사진 업로드 | JPG·PNG·WEBP, 15MB 이하, 브라우저에서 1280px로 줄여 전송 |
| 카메라 | 휴대폰: 기본 카메라 앱(`capture`). PC: 미리보기 창에서 한 장 촬영. 카메라가 없거나 거부하면 파일 선택으로 |
| 진행 상태 | 경과 시간, 취소 버튼, 90초 제한 |
| 결과 표시 | "AI generated" 표시, 누르고 있으면 원본 사진, 옆에 "실제 제품 사진" 별도 표시 |
| 저장 | PNG 저장 시 모서리에 "AI GENERATED · LAGI" 표기를 넣음 |
| 공유 | 브라우저가 지원하면 공유 시트, 아니면 저장 |
| 오류 | 형식·크기 거절, 서버 오류 문구, 연결 실패, 시간 초과를 각각 안내 |
| 개인정보 | 합성 전 동의 체크(사진이 Cloudflare를 거쳐 Google Gemini로 한 번 전송, 라기는 저장하지 않음). Worker 코드도 저장하지 않음 |

### 보안 점검
| 항목 | 결과 |
|---|---|
| API 키 노출 | 없음 — Gemini 키는 Worker 비밀값에만 있음 |
| 허용 출처 | Worker가 LAGI 사이트 주소에서 온 요청만 받음 |
| 제품 이미지 | Worker는 LAGI 사이트의 이미지만 가져옴(임의 URL 불가) |
| 크기 제한 | 사람 사진 4MB, 제품 사진 6MB |
| 중복 요청 | 진행 중에는 버튼 잠금 |
| 호출 제한 | IP당 1분 6회(Worker 인스턴스 단위, 최선 노력). **비용 보호를 확실히 하려면 Cloudflare 대시보드에서 Rate limiting 규칙 추가 권장** |

## 새로 만든 것: 주문서 · 결제
흐름: 장바구니 / 바로 구매 → 주문서(주문자, 배송지, 주소 검색, 상세 주소, 배송 메모) → 동의 → **Worker가 공개된 제품 데이터에서 가격을 다시 읽어 금액 계산** → 토스페이먼츠 결제위젯 → 결제 → 성공 페이지에서 Worker가 승인 API 호출 → 결제 완료(주문번호·금액·배송지·영수증).

| 보안 장치 | 내용 |
|---|---|
| 가격 위조 | 브라우저가 보낸 가격은 쓰지 않음. Worker가 `products/<id>/product.json`을 읽어 계산 |
| 판매 대상 | 이름·가격이 VERIFIED이고 샘플이 아닌 제품만 주문 가능 |
| 금액 변조 | 승인 시 금액이 주문 금액과 다르면 거절 |
| 중복 승인 | 같은 결제키로 다시 요청하면 같은 결과, 다른 결제키는 거절. 토스에 Idempotency-Key 전달 |
| 비밀키 | 토스 시크릿 키는 Worker 비밀값(`TOSS_SECRET_KEY`)에만 |
| 미결제 주문 | 하루 뒤 자동 삭제. 결제된 주문은 보관 |
| 주문 확인 | `GET /admin/orders` + `ADMIN_TOKEN` (관리자용) |
| 배송비 | 주문 안 제품 중 가장 높은 배송비 1회, 그 제품의 무료 기준 이상이면 무료(현재 8개 모두 무료배송) |

결제 키(`VITE_TOSS_CLIENT_KEY`)가 없는 빌드에서는 주문서 오른쪽에 "온라인 결제 연결을 준비하고 있습니다"와 스마트스토어 버튼이 나온다. 가짜 성공 화면은 없다.

## 제품 상세에서 숨긴 것
상세 설명·소재·제작 과정·스토리·선정 이유는 데이터에 있지만 모두 AI 초안(AI_DRAFT)이라 표시하지 않는다. 표시하는 것: 이름, 가격, 스토어 한 줄 설명, 분류, 크기, 배송, 브랜드 표기(LAGI × POPSICLUS).
"WHY LAGI SELECTED THIS?"는 제품별 사유가 확정되지 않아, 모든 제품이 충족해야 하는 공식 네 가지 기준으로 답한다.
