## 구조
- React 18 + TypeScript + Vite 5 + Tailwind 3, HashRouter, GitHub Pages(Actions) 배포.
- 화면: `src/v3/*`(현재 공개 사이트), `src/pages/*`(이전 사이트 /classic), `src/redesign/*`(이전 시안, /classic/v2).
- 데이터: `public/products/<id>/product.json` + `manifest.json`. 필드별로 `status`(VERIFIED / AI_DRAFT / CONTENT_REQUIRED)와 `source`가 붙어 있음.
- 서버: `server/tryon-worker` (Cloudflare Worker) — AI 합성(`POST /`), 회원(`/auth/*`, KV `USERS`).
- 환경변수: `VITE_TRYON_API_URL`(선택, 기본값은 배포된 Worker 주소). Worker 비밀값 `GEMINI_API_KEY`는 Cloudflare에만 있음 — 프론트엔드에는 키가 없음(코드 검색으로 확인).
- `npm run build` 성공. `npm run lint` 오류 0 · 경고 2(fast-refresh 안내). 테스트 스크립트는 package.json에 없음 → Playwright 스크립트로 검증.
- 경로 `src/ar/`, `src/data/`는 확인: `src/ar/`는 이전 작업(사용자 요청 "실시간 증강 빼자")에서 이미 제거됨, `src/data/`는 상품 엔진.

## 기능 분류 (코드 + 브라우저 + 실제 요청으로 확인)

### A. 정상 작동 · 유지
| 기능 | 확인 방법 |
|---|---|
| 상품 목록·상세·카테고리 필터 | Playwright (이전 QA 25개 통과) |
| 장바구니(수량·삭제·로컬 저장) | Playwright |
| 스마트스토어 구매 연결(공식 스토어 홈) | 링크 확인 |
| AI 이미지 합성(사진 업로드/카메라 → Worker → Gemini) | 배포된 Worker에 실제 요청: 잘못된 사진에 `400 사진 형식을 읽을 수 없습니다.` 정상 응답 → Worker 동작 중 |
| 브랜드 영상 자리, 곡선 갤러리, 리본 | Playwright |

### B. 구현되어 있으나 수정 필요
| 기능 | 문제 |
|---|---|
| 홈 갤러리 | 휠 입력을 가로채 페이지가 스크롤되지 않음 → 지침 12-3 위반. 스크롤 연동 방식으로 변경 필요 |
| 결제 | 주문서는 스마트스토어로 넘기기만 함 → 이번에 주소 입력·결제 추가 |
| 상품 상세 설명 | 영어 상세 문구가 스토어 제목에서 만든 초안(AI_DRAFT) → 확인된 정보만 표시하도록 변경 |
| 언어 | 영어 중심 → 이번 지침에 따라 한국어 중심으로 |

### C. 코드만 있음 / 외부 연결 필요
| 기능 | 상태 |
|---|---|
| 회원가입·로그인 | 코드 완성, 로컬 Worker로 E2E 통과. **배포된 Worker는 구버전** — `GET /auth/me`가 `405 POST only`를 반환(회원 라우트 없음). `npx wrangler deploy` 재배포 필요 |
| 상품별 스마트스토어 URL | 8개 모두 스토어 홈 주소만 있음. 상품별 주소 필요 |
| 온라인 결제 | 토스페이먼츠 가맹 계약·키 필요(아래 06 문서) |

### D. 이번 요구사항에서 제거
| 기능 | 처리 |
|---|---|
| 개별 제품 3D 뷰어(회전, GLB, 카메라 조작, 핫스팟, 생성 UI, 플레이스홀더) | `src/three/*`, `/exhibition`, 작업실의 3D 섹션, `ThreeDGenerationProvider`, `@react-three/*` 제거. GLB 10개(13MB)는 삭제하지 않고 `archive/3d-models/`로 이동(배포 제외) |
| 포스터 AR | 이전 요청으로 이미 제거된 상태. 코드는 git 기록과 백업 브랜치에 남아 있어 복구 가능. 새 화면에는 노출하지 않음 |
| 카메라 실시간 거울 피팅 | 이전 요청으로 제거됨. AI 합성용 **사진 촬영**(정지 이미지)은 유지 |

`three` 라이브러리 자체는 About 페이지의 사진 리본(사용자 요청, 제품 3D 아님)이 쓰므로 유지하고 그 페이지에서만 불러옴.

초안(AI_DRAFT)이라 **화면에 표시하지 않는** 항목: 상세 설명, 소재, 제작 과정, 스토리, 선정 이유.
