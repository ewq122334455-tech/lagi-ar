# 02. 레퍼런스 분석 → LAGI 디자인 시스템

## 레퍼런스 측정값
Bureau Dimanche 실측 분석(6개 화면 폭, 측정값 [확인] / 추정값 [추정] 구분)은 `docs/rebuild/02-reference-analysis.md`에 있다(2026-10-23, Playwright로 측정). 이번 작업에서 새로 확인한 것은 아래 두 가지다.

| 항목 | 내용 | 근거 |
|---|---|---|
| Studio 리본 | 이미지들이 끊김 없는 하나의 띠로 이어져 3D 공간에서 휘고, 양 끝에서 화면 쪽으로 말려 들어옴. 스크롤하면 띠를 따라 흐름 | [확인: 캡처 비교] |
| 홈 휠 동작 | 레퍼런스 홈은 페이지가 아니라 캔버스를 움직임(문서 높이 = 화면 높이) | [확인] |

레퍼런스의 로고·사진·문구·Suisse Intl 서체는 쓰지 않았다. 가져온 것은 원리(여백 20px, 상단 2px 선, 3/2/1열 그리드, 검은 푸터가 드러나는 구조, 곡선 갤러리, 클릭 → 앞으로 → 진입 전환)뿐이다.

## LAGI가 다르게 한 것
| 레퍼런스 | LAGI | 이유 |
|---|---|---|
| 홈 = 한 화면 캔버스, 휠을 가로챔 | 홈 = 7개 섹션. DISCOVER 갤러리는 스크롤에 따라 움직임(고정 무대 + 긴 섹션) | 지침 12-3 "스크롤을 강제로 가로채지 않는다" |
| WebGL 평면 | DOM 링크 + CSS transform | 모든 제품이 진짜 링크(키보드·스크린리더) |
| 마스크 없음 | CROP 모티프 마스크(뒤쪽 카드), 모티프 모양으로 사진 일부 → 전체 공개(AGAIN 섹션) | 기존 모티프를 기능적으로 사용 |
| 영문 중심 | 한국어 중심, 영어는 브랜드 단어·메뉴에만 | 이번 지침 |

## 타이포그래피
- 한글: **Pretendard**(모든 방문자에게 jsDelivr로 로드). 영문 브랜드 단어·메뉴: **Posterama 2001**(Adobe Fonts, 대문자 디자인). 폰트 스택에서 Posterama에 한글이 없어 한글은 자동으로 Pretendard로 표시.
- 크기(모바일 / 태블릿 / 데스크톱): Display 56/72/96, H1 30/44/56, H2 36/44/60, H3 22/26/30, Lead 20/24/28, Body 15/16/17, 캡션 13, 라벨 12.
- 한글 자간은 약간 음수(-0.01~-0.02em), 영문 라벨은 +0.06~0.08em.
- 이전에 지정했던 윤고딕100은 웹 라이선스 파일이 없어 방문자에게 보이지 않았으므로 스택에서 뺐다. 웹폰트 파일과 라이선스가 오면 다시 넣을 수 있다.

## 모티프 사용
| 모티프 | 쓰는 곳 | 역할 |
|---|---|---|
| CROP | 홈 갤러리 뒤쪽 카드, AGAIN 섹션 사진 | 사진의 일부만 보여 주고, 앞으로 오거나 마우스를 올리면 전체가 열림 — "다시 보기" |
| POINT | WHY 기준 앞, 대표 제품 캡션 | "이것"을 가리키는 표시 |
| FREEFORM MARK | 사용 안 함 | 장식 반복을 피함. 쓸 자리가 생기면 추가 |
| 공식 로고 | 헤더, 푸터 | 변형 없음, 다른 그래픽과 겹치지 않음 |

## 모션
| 곳 | 동작 | 시간 |
|---|---|---|
| 홈 DISCOVER | 스크롤 → 제품이 차례로 앞으로(감쇠 0.09) | 사용자 입력 즉시 |
| 갤러리 클릭 | 해당 카드가 앞으로 → 중앙에서 확대 → 상세 페이지, 대표 사진이 자리 잡음 | 이동 ≤1.1s + 확대 0.56s + 도착 0.7s |
| About 리본 | 사진 띠가 천천히 흐르고 스크롤로 빨라짐(WebGL, three.js는 이 페이지에서만 로드) | — |
| 페이지 진입 | 0.9s 페이드·상승 | — |
| 모션 줄이기 설정 | 위 애니메이션 모두 끄고 바로 이동 | — |
