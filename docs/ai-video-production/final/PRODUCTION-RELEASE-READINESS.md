# 정식 출시 준비 판정

## 최종 판단: **NO-GO** (정식 출시 불가)
이유 한 줄: 실제 Decart AI가 만든 영상을 **단 한 번도 확인하지 못했다.** 요구된 정식 완료 기준 10개 중 핵심 6개가 검증되지 않았다.
- 승인된 **10초 1회 스모크**를 진행하기 위한 조건은 **CONDITIONAL GO**(아래 3).

## 2. 완료한 것 / 미해결
- 완료(IMPLEMENTED·LOCALLY VERIFIED): 카메라 우선 시작, 단계·오류 UX, 종료 처리, 로컬 녹화, 측정 기록, 동시 세션 제한, 사용 원장, 킬 스위치, 사전 점검·비공개 설정·잔액 기록 도구, 동일 입력 모델 비교 도구.
- 미해결: 실제 출력 품질 전체, 모델 선택 근거, 상품 7개의 컷아웃, 사진 1장뿐인 자산, 나머지 3개 상품의 정체, 모바일 실기기, 공급자 과금 대조.

## 3. 10초 1회 스모크의 조건 (CONDITIONAL GO)
| 조건 | 상태 |
|---|---|
| 로컬 설정·사전 점검(세션 10초, 일 2, 동시 1, localhost, Gemini 없음) | **충족**(사용자 Mac, 전부 OK) |
| 잔액 | 충족(1274크레딧, 시험 20크레딧) |

| 사용자 명시 승인 "시험 시작해도 돼" | **없음 → 실행 안 함** |

## 4. 필요한 사용자 작업
1. 위 승인 문장 + (권장) 크레딧 상한이 있는 시험용 키, 자동 충전 끄기 확인.
2. 승인 후 `SMOKE-TEST.md` 순서로 daily-tote 10초 1회, 결과(녹화·측정 JSON·잔액 차이) 전달.
3. (이후) 같은 입력 클립으로 두 모델 비교 2회, 상품 3~5개 확대, iPhone·Android 실기기.
4. 나머지 3개 상품 정보, 상품별 후면·측면·로고 사진.
5. 공급자 계정: 월 예산·사용량 알림, 동시 세션 한도 설정.

## 5. 출시까지의 순서
스모크 → (통과 시) 모델 비교·상품 확대 → 실기기 3종 → 비용 대조 → 운영 설정 설계 적용(배포 승인) → '베타' 표시 제거 결정 → main 병합·운영 배포(별도 승인). **'베타' 표시는 유지한다.**
