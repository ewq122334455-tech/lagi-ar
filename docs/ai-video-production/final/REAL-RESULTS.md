# 실제 Decart 시험 결과 기록 (사용자 Mac, 사용자 화면 캡처 기준)

모의가 아닌 **실제 Decart 연결**로 얻은 결과만 적는다. 판단 근거는 사용자가 보내 준 화면 캡처와 측정 기록이며, 영상 파일 자체는 이 세션에 없다.

| # | 조건 | 결과 |
|---|---|---|
| 1 | 로컬 **개발 서버**(`npm run dev`), `lucy-2.6`, 10초, 표준 | 연결·토큰 성공, **AI 영상 0프레임**, 과금 0 (Vite 개발 서버가 SDK의 `frame-metadata-worker.js`를 제공하지 못함, 같은 경로가 404) |
| 2 | 로컬 **운영용 빌드**, `lucy-2.6`, 10초 | 생성 시작(SDK 상태 `generating`@3.7s), 영상 도착 1280×720·13.2fps, 끊김 0 |
| 3 | 운영 사이트, `lucy-vton-3.6` + **초록 합성 켬** | AI 생성 신호 15.5초, 17.3fps. 상품 사진을 오려 붙인 모양, 아래가 잘리고 평평함, 몸통 쪽 판 모양 조각 |
| 4 | 운영 사이트, `lucy-vton-3.6` + **초록 합성 끔**(Anywear 방식) | 가방이 손에 **자연스럽게 들린 모습**. 빨간 손잡이를 잡고 무게감 있게 접힘. 큰 인상(흰 바탕·남색·빨간 손잡이)은 맞지만 무늬는 단순화, 가방이 구겨져 보임 |

## 확인된 사실
- Decart가 **세션 길이를 직접 강제**한다: `Session duration limit reached`로 20.8초(요청 20초)에 끊었다.
- 연결 후 **약 5~6초가 지나서야 생성이 시작**된다(첫 생성 신호 8.7초, 15.5초 시점은 각각 연결 후 약 6.3초, 5.6초). 20초 세션의 실제 생성 시간은 약 14초.
- 초록 합성 방식은 상품 **사진 한 장(평면)** 을 붙이는 구조라 회전할 수 없다.
- 개발 서버에서는 영상이 오지 않으므로, **실제 시험은 운영용 빌드로** 해야 한다.

## 확인되지 않은 것
- 상품 디자인 충실도(로고·글자·무늬)는 Anywear 방식에서 실제와 다를 수 있다. 정확한 모습은 "이 포즈로 정확한 사진 만들기"(실제 상품 합성)로 보완한다.
- 다른 상품(plano-bag 등), 모바일 실기기, 장시간 반복 사용, 실제 크레딧 차감액은 미확인.

## 결정 (2026-11-17)
AI 영상의 **기본 방식을 Anywear 방식**(`lucy-vton-3.6`, 초록 합성 없음)으로 변경. 이전 방식은 주소에 `&model=lucy-2.6&map=1`을 붙여 쓸 수 있다.
