# 비용·세션 안전 보고

**원칙: 토큰 발급 횟수 상한은 금액의 절대 상한이 아니다.** 아래는 코드가 강제하는 것, 공급자(Decart) 쪽에 달린 것, 확인되지 않은 것을 구분한다.

## 1. 현재 보호 장치 (검증 수준)
| 위험 | 장치 | 검증 |
|---|---|---|
| 동시 세션 초과 | DO 임대: 방문자 1, 사이트 `REALTIME_MAX_CONCURRENT`(기본 3, 테스트 설정 1) | **실제 workerd + 실제 DO 11/11**, 모의 DO 10/10 |
| 세션 종료 실패·브라우저 강제 종료 | 클라이언트 신호를 믿지 않음: 임대는 35초 후 자동 만료, 세션 길이는 토큰 `maxSessionDuration`(공급자 강제) | 임대 만료 실제 workerd 확인 / **공급자가 실제로 끊는지는 NOT VERIFIED** |
| Worker 재시작 | 임대·카운터가 DO 저장소에 있음 | 실제 workerd에서 재시작 후 유지 확인 |
| 사용자별 제한 우회 | IP당 일 3회(테스트 2), 사이트 일 100회(테스트 2), 실패 시 차단·환불 없음 | 확인. IP 변경(VPN)에는 사이트 한도가 마지막 방어선 |
| 과도한 재연결 | 클라이언트는 자동 재연결 없음, 재시작은 새 토큰·새 유닛 | 확인 |
| API 키 노출 | 영구 키는 Worker에만, 브라우저는 20초 토큰, 번들 검사에 키 없음 | 확인 |
| unmetered 모드 | 모든 허용 출처가 localhost일 때만 | 확인 |
| Gemini와 Decart 예산 | 별도 카운터 범위(`tryon`/`rt`) | 확인 |
| 즉시 중지 | `REALTIME_DISABLED=1`(토큰 발급 중단) | 모의 DO 테스트 확인 |
| 내부 기록 | `/admin/usage`(토큰 수, 예약 초, 페이지 보고 초, 추정 USD) | 실제 workerd 확인 |

## 2. 코드로 막을 수 없는 위험
1. **토큰 한 개로 다중 연결**: 공식 문서에 토큰당 연결 제한이 없고, 만료는 이미 열린 세션을 끊지 않는다. 만료 20초 안에 복사한 토큰으로 여러 연결을 열면 연결마다 세션 상한까지 과금된다. 우리 서버는 WebRTC 연결을 볼 수 없어 막지 못한다.
2. **공급자 측 한도가 현재 없음(조회 결과)**: 동시 세션 한도 `null`(제한 없음), 이 키의 크레딧 상한 없음, 잔액 1274크레딧(≈$12.74). **자동 충전·월 예산은 미확인.**
3. **내부 기록 대 공급자 과금**: 내부는 "예약 초"와 "페이지 보고 초"뿐. Decart는 "active generation" 초를 과금하며 큐 대기·무프레임 구간의 청구 여부는 문서에 없다. 차이는 시험 전후 `GET /v1/credits` 대조로만 알 수 있다(미측정).
4. **소유자 계정**: `REALTIME_UNLIMITED` 이메일은 일일 한도 면제. 사용하지 않으면 비워 둔다.
5. 키 유출 시 상한: 키 자체에 크레딧 상한이 없으면 잔액 전부. **키에 상한 설정 권장**(공식: `key_quota` 키는 상한이 공급자 쪽에서 강제됨; 설정 화면 위치는 문서에 없어 미확인).

## 3. 운영용 설정 설계 (적용하지 않음, 승인 후 결정)
| 항목 | 시험(현재 로컬) | 제안: 첫 공개 베타 |
|---|---|---|
| 세션 길이 | 10초 | 20초 |
| 방문자(IP)당 하루 | 2 | 2 |
| 사이트 하루 | 2 | 20 |
| 동시 | 1 | 2 |
| Gemini(컷아웃) | 비활성 | 사전 생성·캐시된 컷아웃만(`pregenerate-cutouts`), 일 유닛 낮게 |
| 키 | 시험용 | **크레딧 상한이 있는 별도 운영 키**(예: 월 1000크레딧=$10), 자동 충전 끔, 사용량 알림 |
| 최대 일일 노출 | $0.40 | 20 × 20초 × $0.02 = **$8/일**(키 상한이 월 $10이면 그 이상 불가) |
| 즉시 중지 | `REALTIME_DISABLED` | 같은 방식(Worker 환경 갱신 필요 = 배포 승인 사항) |
이 값은 코드 상수 `REALTIME_PER_IP`(현재 3)와 환경변수로 구성된다. 운영 Worker 변경은 배포 승인이 필요하다.

## 4. 시험 중 중단 규칙
실제 세션이 12초 초과, 차감 > $0.30, 종료 1분 뒤에도 `quota.active` ≠ 0, 토큰 2개 이상 발급 → 추가 호출 중단, `REALTIME_DISABLED=1`, 보고.

## 5. 이번 작업의 실제 지출
**Decart 0원, Gemini 0원.** 읽기 전용 조회 2건(사용자 Mac, 시험 전 잔액)만 실행됐고 잔액 변화는 확인되지 않았다.
