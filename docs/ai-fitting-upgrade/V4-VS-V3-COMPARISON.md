# V3 ↔ V4 비교 — 손 위치 지연·이동 정확도·복귀 튐 (같은 녹화 데이터)

**V4 = V3 + 선행(lead) 보정**(`?engine=v4`, 실험). 선행: 마지막 감지 이후 경과 시간 × 직전 두 감지로 구한 손 속도만큼 위치를 앞으로 밀기. 정지한 손에는 적용하지 않고(속도 0.3 손바닥폭/초 미만은 0, 1.0에서 전부), 이동량은 손바닥 폭의 0.6배로 제한. 조정한 상수 없음(경과 시간이 곧 선행량).

**데이터**: 사용자 손 녹화 3종(`fist3` 정지, `fist3-pan` 좌우 이동, `fist3-drop` 중간에 손 가림)을 MediaPipe로 추적한 **실제 출력 180프레임**. 빠른 손은 같은 이동을 시간 압축한 **합성 속도**(×4, ×8). 단위 '손바닥 폭'은 검지~새끼 마디 거리(영상에서 약 96px). 코드: `tools/sync-study.mjs`, `tools/loss-study.mjs`; 원자료: `data/sync-study.json`, `data/loss-study-v4.json`.

## 3. 판정 (측정에 근거한 것만)
| 항목 | 결과 | 상태 |
|---|---|---|
| 정지한 손 | V3와 동일(오차 0.001, 떨림 0.02) — V4가 정지 시 아무것도 바꾸지 않음 | **VERIFIED** |
| 이동 중 위치 오차 | 느린 감지(5Hz)를 뺀 모든 조건에서 평균 **−17~−36%**, p95도 대부분 감소. 가장 큰 개선: 15Hz에서 0.175→0.112 손바닥 폭(−36%, 약 17px→11px). 감지가 5Hz까지 느려지면 개선은 −5%로 사라지고 p95는 오히려 약간 나빠짐(0.707→0.736) | **VERIFIED (오프라인, 녹화 데이터)** |
| 움직임의 거칠기(프레임 간 가속도) | 이동 중 **약 1.9~2.1배로 증가**(5.7→11.7px 등). 위치는 맞지만 움직임이 덜 부드러움 | **FAILED (악화)** — 눈에 어떻게 보이는지는 NOT TESTED |
| 손 유실·복귀(느린 손) | 오표시 2%→1%, 복귀 시 최대 이동은 같거나 +7px(20→27) | PARTIAL (사실상 동일) |
| 손 유실·복귀(빠른 손 ×4) | 평균 오차 −4~−5%, 오표시 −3%p, **복귀 시 최대 이동 +34~+59%**(53→71, 53→69, 99→157) | **FAILED (복귀 튐 악화)** |
| 손 유실·복귀(×8) | V3와 동일 수준(오표시 48~50%로 둘 다 나쁨) | 해결 안 됨 |
| 실기기에서의 체감 | 측정한 적 없음 | **NOT TESTED** |

**종합**: V4는 "가방이 손을 뒤쫓는 거리"를 줄이는 대신 **움직임이 거칠어지고 빠른 손의 복귀 튐이 커지는** 교환입니다. 이 교환이 더 자연스러운지는 숫자로 결정할 수 없고 사용자가 보고 판단해야 합니다. 그래서 V4는 **실험용 옵트인으로만 유지**하며 기본값 후보가 아닙니다. 사용자의 실기기 영상(`V4-NATURALNESS.md`의 B·C·E)이 오면 같은 입력으로 V3/V4를 나란히 재생해 선택하겠습니다.

**참고**: 이 표의 V3 수치는 최종 V3 코드(적응형 검출 간격 포함) 기준이라 `V3-LOSS-REANALYSIS.md`의 초기 V3 표와 다릅니다(그 문서의 V3 유실 평균 오차 18.8~27.5px → 최종 코드 13.7~14.7px). 비교는 같은 실행의 V3↔V4만 유효합니다.
