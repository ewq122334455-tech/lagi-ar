## 2. 10가지 질문에 대한 답

1. **실제로 개선됐나?** 일부만. 실시간 회전·유실 처리와 안내 UI는 측정으로 확인. 사진 합성 품질은 확인 못 함.
2. **AI 사진 품질은?** 평가하지 못했음(유료 호출 없음).
3. **실시간 위치 정확도는?** 개선되지 않음.
4. **가장 큰 품질 문제는?** 참조 컷아웃이 AI 재생성이라 제품이 달라질 수 있음, 접촉 그림자 없음, 사진에서 사람이 제품을 가림.
5. **모델 문제인가 입력 문제인가?** 둘 다. 의류 중심 모델 + 가려진 제품 사진.
6. **Anywear 수준 가능한가?** Anywear는 의류 서비스이며 가방 근거를 못 찾음. 같은 기술(Decart)을 이미 사용 중. 동급이라고 말할 근거 없음.
7. **교체가 답인가?** 아직 아님. 근거 없이 교체하면 위험. 먼저 A/B로 현재 구조의 실제 품질을 측정.
8. **제품별 최적 방식은?** 아래 표.
9. **비용·개인정보 위험은?** 새 비용 없음. 외부 전송 데이터는 기존과 동일(사진은 Worker 경유 Gemini). 변경 없음.
10. **지금 배포해도 되나?** 비유료·옵트인 변경은 안전하나 배포는 승인 후.
