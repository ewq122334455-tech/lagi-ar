## 2. 구현
- `src/v3/bag3d.ts` — `createBagLayer(…, {realism})`: `ShadowMaterial` 포착면(512px 그림자맵 1장, PCFSoft), 방 색(tint) 반영, 조명 보정, 레이어 투명도.
- `src/v3/MapTryOn.tsx` — 엔진 선택 `engineOf()`, 손잡이 꼭대기 상한, 사람 마스크 교차, 손/가방 접촉 음영(손 픽셀에만, 가방 픽셀에만 적용), 방 색 추정(4곳 평균), `HoldPolicy`·`Swing` 연결.
- `src/v3/fitFilter.ts` — `HoldPolicy`, `Swing`.
- 그림자는 카메라 깊이가 없으므로 **몸/옷이 가방 바로 뒤에 있다고 가정한 그럴듯한 단서**이지 측정값이 아닙니다.

## 3. 같은 영상·같은 제품의 V1 | V2 | V3 (`images/v3/`)
녹화한 손 영상(`fist3`)을 가짜 카메라로 넣고 실제 앱 화면을 캡처. 헤드리스 소프트웨어 렌더라 속도는 대표성이 없고, 정지 영상이라 같은 프레임으로 볼 수 있습니다. 영상 속에는 실물 검정 가방이 원래 찍혀 있습니다(우리 렌더 아님).
- `cmp-daily-tote.png` — **가장 큰 차이**: V1/V2에서는 손이 빨간 손잡이 고리 사이에 떠 있고, V3에서는 주먹이 손잡이를 쥐고 가방이 그 아래에 매달림. 가방이 더 밝고 흰색에 가까움. 주먹 가장자리 후광 감소.
- `cmp-glasses-case.png`, `cmp-milkpack-earphone-case.png` — V3에서 카라비너가 주먹에 걸린 모양이 보이고(연결), 소형 케이스 아래 소프트 그림자가 보임.
- `cmp-plano-bag.png`, `cmp-modular-bag-s.png` — 손잡이가 짧은 제품은 위치가 거의 같고 차이는 밝기·미세한 음영뿐.
- 정직한 한계: 후드티처럼 어두운 배경에서는 그림자가 거의 안 보임. V1과 V2는 렌더링이 같아 구분되지 않음.

## 4. 가림(occlusion)이 어디까지 되는가
| 상황 | 상태 |
|---|---|
| 손가락이 손잡이 앞 | 기존에도 가능(손 전체를 가방 위에 덮음). V3: 후광 정리 |
| 팔이 제품 앞을 가로지름 | **불가** — 깊이 정보 없음. 팔이 가방 앞/뒤인지 알 수 없어 구현하지 않음(**UNSOLVED**) |
| 제품이 몸 뒤로 이동 | **불가**(동일 이유) |
| 깊이 없는 상황의 처리 | 손으로 쥔 경우에만 "손이 앞"이라는 규칙 적용 |
