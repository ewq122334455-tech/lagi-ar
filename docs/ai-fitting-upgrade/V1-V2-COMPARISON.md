# V1 ↔ V2 비교 (같은 조건)

**방법**: 사용자 손 녹화 영상 3종(`fist3` 정지·`fist3-pan` 이동·`fist3-drop` 손 1초 가림)을 MediaPipe HandLandmarker에 프레임별로 통과시켜 실제 추적 출력을 얻고, V1과 V2의 평활을 **같은 입력**에 60Hz 렌더 / 15Hz 검출로 재생. 코드: `tools/fit-sim.mjs`, 결과: `data/realtime-sim-results.json`, `data/realtime-sim-table.txt`.

| 지표 | V1 | V2 | 판정 |
|---|---|---|---|
| yaw 가속도 RMS (정지/이동) | 0.006~0.008 | 0.001~0.002 | 개선 (4~6배) |
| 이동 중 위치 가속도 RMS (px/frame²) | 5.1 | 5.7 | 동급 (개선 아님) |
| 정지 시 위치 지연 | 기준 | +34ms | 약간 악화 |
| 손 유실 시 가방 가시율 | 53% | 87% | 개선 |
| 손 유실 최대 공백 | 550ms | 217ms | 개선 |
| 정지 손 떨림 | <1px | <1px | 차이 없음 |

## 한계
- 시뮬레이션은 **추적 출력의 평활**을 비교합니다. 화면 렌더, GPU, 카메라 지연은 포함하지 않습니다.
- 샘플은 한 사람의 손 1세트(180프레임)입니다. 다양한 피부색·조명·기기에서의 일반화는 **미검증**.
- 헤드리스 소프트웨어 WebGL은 1~2fps라 브라우저 안에서의 체감은 평가하지 못했습니다. V1/V2 모두 브라우저 스모크(오류 0, WebGL 컨텍스트 누수 0)는 통과.
