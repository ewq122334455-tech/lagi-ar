# V5 — 비용 안전성

**먼저 한 줄 요약**: 호출 **시도 횟수**는 정확히 제한됩니다(VERIFIED, 모의 환경). 그러나 시도 횟수 제한은 **금액의 절대 상한을 보장하지 않습니다.** 금액은 Google·Decart의 실제 과금 방식과 단가에 달려 있고, 그쪽 한도는 사용자가 설정해야 합니다. 이 문서의 모든 시험은 **모의 Gemini/Decart**(로컬 서버)로 했고, **유료 호출은 0회**입니다.

## 1. 1유닛의 정확한 정의
| 범위 | 1유닛 | 상한(기본값) | 코드 |
|---|---|---|---|
| Gemini 사진 합성 | **Gemini 이미지 모델로 나가는 HTTP 요청 1회**(재시도·컷아웃·매트 포함, 방문자 요청 1건이 아님) | 사이트 400/일, 주소당 24/일 | `callGemini` → `takeUnits` → `meter('tryon')` |
| Gemini 텍스트(제품 설명) | 0.1유닛 | 같은 합계에 포함 | 같은 경로 |
| Decart 실시간 | **토큰(=최대 20초 세션) 발급 1회** | 사이트 100/일, 주소당 3/일 | `realtime` → `meter('rt')` |
- 모든 유료 호출 **직전**에 예약(reserve-before-call). 예약 실패 = 호출 없음.
- 하루 단위(UTC 날짜)로 Durable Object 1개씩. 정수(centi-unit)로 저장.

## 2. 모델별 실제 과금 구조 (**공개 가격표 기반 추정 — 확인 필요, 가격은 바뀔 수 있음**)
| 대상 | 과금 | 1유닛의 대략 금액 |
|---|---|---|
| Gemini 2.5 Flash Image | 출력 이미지 1장당 약 USD 0.039(이미지 출력 토큰 단가×약 1,290토큰) + 입력 토큰(텍스트·이미지 약 USD 0.30/백만 토큰) | 약 USD 0.04 |
| Gemini 텍스트 모델 | 토큰당, 이미지 대비 극히 작음 | 약 USD 0.001 이하(0.1유닛은 보수적 과대 계산) |
| Decart 실시간 | 초당 과금(출처에 따라 USD 0.02/초 등으로 상충) | 20초 세션 ≈ USD 0.40 — **Gemini 1유닛의 약 10배** |
- 그래서 **Decart는 별도 상한**을 둡니다: 사이트 100세션/일 ≈ USD 40/일 vs Gemini 400유닛/일 ≈ USD 16/일(추정).
- 입력 비용: 요청은 사람 사진(최대 4MB)·컷아웃·실물 표면 사진(최대 3장)을 보냅니다. 이미지 입력 토큰은 장당 수백~천여 토큰으로, 합쳐도 이미지 출력 단가의 몇 % 수준(추정). 큰 사진이 비용을 크게 바꾸지는 않지만 **정확한 값은 청구서로 확인**해야 합니다.

## 3. 호출 시도 ≠ 과금 발생
| 상황 | Google이 과금하는가 | 우리의 계산 |
|---|---|---|
| 이미지 정상 생성 | 예 | 1유닛 |
| 안전 필터로 막힘(HTTP 200, 이미지 없음) | 입력 토큰은 과금될 수 있음(**확인 필요**) | 1유닛(재시도 시 각각) |
| 429/503 | 일반적으로 과금되지 않음(**확인 필요**) | 1유닛(환불 없음) |
| 네트워크 오류/시간 초과 | Google이 처리했다면 과금될 수 있음 | 1유닛 |
→ 우리는 **과금 가능성이 있는 모든 시도를 센다**(보수적). 그러나 이것이 "청구액 ≤ 유닛 수 × 단가"를 보장하지는 않습니다: 단가 인상, 출력 토큰 증가(생각 토큰 등), 모델 교체, 입력 크기 증가가 모두 유닛당 금액을 바꿉니다.

## 4. 환불 정책 (유지: 환불 없음)
예약한 유닛은 **어떤 경우에도 돌려주지 않습니다.** 이유: ① 실패한 호출도 과금됐을 수 있음 ② 환불 경로 자체가 상한을 우회하는 수단(실패 유발 → 환불 → 재호출) ③ 코드가 단순해져 이중 환불이 구조적으로 불가능. 결과: 일일 예산은 방문자의 권리가 아니라 **지출 상한**.

## 6. 운영 환경에서 `TRYON_QUOTA=unmetered`가 쓰일 수 없게 한 장치
| 장치 | 동작 | 검증 |
|---|---|---|
| 런타임 | `unmetered`는 `ALLOWED_ORIGINS`가 **전부 localhost/127.0.0.1**일 때만 허용. 실제 도메인이 하나라도 있으면 **호출 거부(503)** | VERIFIED(3종 시험) |
| 배포 검사 `scripts/check-worker-config.mjs` | 설정 파일에 `TRYON_QUOTA`/`unmetered`가 있거나, `QUOTA` 카운터 바인딩·마이그레이션이 없거나, 상한 값이 숫자가 아니거나 범위를 벗어나거나, 출처에 와일드카드·localhost·자리표시자가 있으면 종료 코드 1 | VERIFIED: 운영 파일 통과, 스테이징 템플릿은 자리표시자 때문에 차단, 나쁜 파일 3종 차단 |
| 배포 워크플로 | `deploy-worker.yml`이 배포 전에 위 검사를 실행(실패하면 배포 중단). **이 워크플로 변경은 main에 합쳐질 때만 효력**이 생기며 이번에 실행하지 않음 | 파일 구문 확인만, **NOT TESTED**(실제 Actions 실행 안 함) |
| 한계 | Cloudflare 대시보드에서 직접 변수를 추가하면 이 파일 검사는 못 잡지만 런타임 거부가 막음 | — |

## 7. 사용자가 해야 하는 Google·Decart 쪽 통제 (우리 코드가 대신할 수 없음)
- **Google Cloud**: ① Gemini API 프로젝트의 **일일 요청 쿼터를 낮게 설정**(콘솔 → 쿼터) — 하드 제한에 가장 가까운 수단 ② **결제 예산 알림**은 알림일 뿐이며 지출을 **자동으로 멈추지 않습니다**(자동 중단은 별도 구성 필요) ③ 스테이징·운영에 **서로 다른 API 키**.
- **Decart**: 계정의 월 사용량 한도·알림 설정(Decart 대시보드 기능은 확인하지 못함 — **확인 필요**).
- 위 설정 전에는 **외부 사용자 공개를 하지 않는 것**이 안전합니다.

## 8. 아직 남은 비용 위험
1. 상한은 시도 횟수이지 금액이 아님(§3).
2. 다수의 주소를 쓰는 공격자는 사이트 상한(400유닛 ≈ USD 16, Decart 100세션 ≈ USD 40/일, 추정)까지는 쓸 수 있음 — 이 값이 감당 가능한지는 소유자가 결정.
3. 캡차(Cloudflare Turnstile)·Rate Limiting 규칙은 미구현(`V4-PUBLIC-ACCESS-ARCHITECTURE.md` 권고).
4. UTC 자정에 카운터가 초기화됨(한국 시간 오전 9시).
5. 실제 Cloudflare 엣지 환경 시험은 NOT TESTED(로컬 workerd만).
