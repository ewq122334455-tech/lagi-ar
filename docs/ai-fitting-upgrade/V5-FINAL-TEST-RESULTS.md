## 4. 남은 문제
1. 절대 크기: 손 크기 추정 두 방식의 1.44배 차이 중 ①기하 오류(약 1.2배)는 확인·V5에서 선택 가능하게 함, ②개인차(약 1.2배)는 **기준물 영상 없이는 미해결**.
2. 손잡이 접촉·회전·관성의 현실감: 영상 없이 검증 불가(BLOCKED).
3. 팔·몸 가림(깊이), 소재 광택: 미해결.
4. 실기기 FPS·발열·감지 속도: 미측정.
5. Gemini 생성 품질(로고·질감·접촉): 유료 호출 없이는 평가 불가.
6. 비용: 시도 횟수 상한 ≠ 금액 상한; Google 쿼터·결제 한도 설정은 사용자 몫.
7. 새 제품이 동시에 몰리면 예산이 컷아웃에 먼저 소진될 수 있음(사전 생성으로 회피).
8. 제품 데이터: 검증된 실제 제품은 8개(요청서의 11개와 불일치 — 임의로 맞추지 않음), 데일리 파우치백·북커버 3D 없음, 오리가미 피크닉백 3D 앞면 회색.

## 5. 외부 사용자 테스트 가능 여부
**아직 불가.** 막는 문제: 인터넷 공개·스테이징 배포 미승인, 비용 안전장치(`QUOTA` 바인딩·마이그레이션)가 아직 어디에도 배포되지 않음(없이 배포하면 AI가 전부 503으로 막힘 — 의도된 안전 동작), Google·Decart 한도 미설정, 테스터 동의·명단 없음, 실기기 품질 미확인.
