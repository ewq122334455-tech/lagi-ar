## P1 추가 시험: 비생성 컷아웃은 가능한가

`magic_touch.tflite`(MediaPipe 대화형 분할)로 8개 제품 메인 사진에 같은 점(이미지 중앙)을 눌러 마스크를 만들었습니다.

- **데일리토트백**(밝은 단색 배경): 제품 영역이 정확히 잡힘 (손잡이 구멍 일부는 막힘)
- **플라노백**(사람이 메고 있는 사진): 가방이 아니라 **사람 몸통**이 선택됨
- **모듈러백**: 가방 윗부분만 선택, 아랫부분 일부 빠짐
- **안경 보관함**(사람 손과 옷 사이): 손·옷이 섞여 선택

결론: 비생성 분할은 **깨끗한 배경의 사진에서만** 믿을 수 있고, 6/8 제품의 사진처럼 사람이 제품을 가린 경우에는 점 위치를 제품마다 직접 지정해도 가려진 부분을 복원하지 못합니다. 그래서 이번에는 **적용하지 않았고**, 해결책은 "깨끗한 제품 정면 사진 확보"(사용자 데이터)입니다.
