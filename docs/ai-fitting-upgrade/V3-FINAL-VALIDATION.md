## 3. 제품별 품질 평가
조명 이득: 평평한 sRGB 128/220 박스를 같은 렌더러로 그려 `렌더값/원본`(1.0=정확). 보통 밝기(b=0.6): V2 0.79 → V3 0.98(정면), 측면 0.76 → 0.92.
제품별 렌더 평균색 ÷ 원본 표면 사진 평균색(V3, 정면, `data/render-color-v3.json`): 이 값은 렌더 영역과 사진 영역이 정확히 일치하지 않아 **±15% 오차**가 있습니다(통제 시험이 더 신뢰할 수 있음).

| 제품 | 색 비율 V3 (V2) | 렌더 가로세로비 / 치수 기준 | 3D가 원본과 다른 점 (확인된 것) | 평가 |
|---|---|---|---|---|
| 플라노백 | 1.14 (0.82) | 0.64 / 0.69 | 흰 인쇄 질감이 포스터화되어 보임(원본 텍스처 해상도·대비) | 색 PARTIAL(약간 밝음) |
| 데일리 토트 | 0.82 (0.66) | 0.70 / 0.74 | 뒷면·측면 텍스처 사용, 손잡이는 단순 관 | 형태 PARTIAL |
| 모듈러백 S | 1.05 (0.85) | 0.74 / 0.80 | 손잡이 단순화 | 양호 |
| 안경 케이스 | 1.10 (0.89) | – (파우치) | 단순 슬랩 | 양호 |
| 이어폰 케이스 | 0.89 (0.74) | – (파우치) | 줄·캡 장식은 근사 | 양호 |
| 오리가미 피크닉백 | 1.00 (0.81) | 1.24 / 1.33 | **앞면 텍스처가 회색 단색**(상품 사진은 빨강·흰색). 나머지 면은 단색 대체. **어느 쪽이 실물인지 확인 필요 — 수정하지 않음** | **UNSOLVED(데이터)** |
| 데일리 파우치백 / 북커버 | – | – | 3D 없음 | **BLOCKED** |

- **형태**: 렌더 가로세로비가 치수 기준보다 일관되게 6~8% 낮음 — 0.12rad 기울임으로 윗면이 보이고 가장자리 파이핑 두께가 더해진 결과로 설명되며(모든 제품에서 동일한 방향), 제품 치수와 3D 비율은 일치하는 편입니다. 부드러운 소재(피크닉백)가 단단한 상자로 표현되는 한계는 그대로입니다.
- **재질(광택·반사)**: 소재별 거칠기 한 값만 사용. 원본의 광택(예: 버클 금속)과의 일치는 사진과 대조할 기준이 없어 **검증하지 못함**. **UNSOLVED**.

## 4. 접촉 그림자·가림 개선 가능성
| 항목 | 현재 | 가능성 | 권고 |
|---|---|---|---|
| 포착면 그림자 | 구현. 밝은 배경·소형 제품에서 보임, 어두운 옷 위에서 안 보임 | 불투명도를 배경 밝기에 맞춰 조절 가능(작은 개선) | 실기기 확인 후 |
| 손↔가방 접촉 음영 | 구현(손 픽셀·가방 픽셀에만) | 손가락 굽힘을 이용한 정밀 접촉점은 손 랜드마크 21점으로 가능하나 효과 크기 불명 | 보류 |
| 팔·몸에 가려짐 | 불가 | 단안 깊이 모델(추가 수십 MB, 모바일 부담) 필요. 포즈의 상대 z로 "팔이 앞/뒤"를 판정하는 규칙은 가능하나 정답 데이터 없이 검증 불가 | 별도 연구 과제 |
| 손가락이 손잡이 앞 | 기존 방식(손 전체가 앞) + 후광 정리 | 현재 수준이 한계 | – |

## 5. 해결하지 못한 문제 목록
1. 이동 중 위치 지연·오차(필터 한계, 정체 확인)
2. 빠른 손(합성 8배)에서 유실 시 오표시 52%(V1 41%보다 나쁨)
3. 접촉 그림자의 사실감(어두운 배경에서 안 보임)
4. 팔·몸에 의한 가림(깊이 없음)
5. 재질 광택·반사
6. 피크닉백 3D 앞면 텍스처(데이터 확인 필요), 부드러운 소재의 형태
7. 파우치백·북커버 3D 없음
8. AI 사진 합성 품질 전반(유료 호출 미실시)
9. 실기기 FPS·발열(도구만 준비)
10. 진자 흔들림의 영상 확인(정적 캡처로는 못 봄)
