# 모델·API 비교와 선택지

**출처 주의**: 아래 외부 서비스 정보는 웹 검색 결과입니다. Anywear 공식 페이지(anywear.decart.ai)와 Perfect Corp 문서(yce.perfectcorp.com)는 이 세션 네트워크에서 열리지 않아 **직접 확인하지 못했습니다.** 비공개 내부 구조는 추측하지 않았고, 가격은 출처마다 달라 **미검증 추정치**입니다. 어떤 서비스도 이번 세션에서 호출하지 않았습니다.

## 1. 비교표

| 서비스 | 대상 | 방식 | 가방 적합성 | 비용(추정) | 상태 |
|---|---|---|---|---|---|
| **현재: Gemini 2.5 Flash Image** | 일반 이미지 편집 | 사람 사진 + 제품 참조 + 프롬프트 | 가능하나 제품 충실도 **미검증** | 이미지당 약 $0.04 안팎(미검증) | 운영 중 |
| **현재: Decart lucy-2.6 (실시간 영상)** | 영상 변환 | 20초 세션 | 제품을 다른 가방으로 그린 사례 확인(Q2) | 초당 ≈$0.02 → 20초 ≈$0.40 (출처 상충) | 운영 중, 디자인 고정으로 완화 |
| **Anywear (Decart Lucy V-TON)** | **의류** 중심 | 실시간 가상 착용 | 가방 사례 근거 **없음**. LAGI는 이미 같은 회사의 lucy-2.6 사용 | 무료 베타 | 공식 확인 불가 |
| Perfect Corp 가방 착용 | 숄더·크로스백 | 실시간 AR + API | 가방 전용 기능이 있다고 자체 홍보(독립 검증 못 함) | 계약 필요 | 미검증 |
| Pianmi 핸드백 API | 핸드백 | 이미지 기반 | 홍보 자료만 확인 | 미확인 | 미검증 |

## 2. 선택지

| | A. 현재 구조 개선 | B. 일부 교체 | C. 하이브리드 |
|---|---|---|---|
| 내용 | 프롬프트 v2, 사진·결과 점검, 실시간 V2 | 사진 합성 또는 영상 공급자를 교체 | **제품 특성별로 엔진 선택**: 3D 가능 제품은 실시간 3D, 사진은 Gemini(+옵트인 v2), 영상은 보조 |
| 비용 | 추가 없음(테스트 호출은 별도 승인) | 공급자 계약·통합·재검증 | A와 같음 + 제품 데이터 보강 |
| 위험 | 생성 품질이 오르는지 **미검증** | 가방 품질이 의류보다 나쁠 수 있음, 개인정보 처리 변경 | 엔진별 분기 유지 비용 |
| 사용자 승인 필요 | 유료 A/B만 | 계약·개인정보 | 데이터(사진) 제공 |
| 이번 세션 | **구현·검증 완료**(비유료 부분) | 시도하지 않음 | 제품별 권장표(FINAL-RECOMMENDATION)로 정리 |

**권장: C(하이브리드), 단 A를 먼저.** 이유: ① A는 비용·계약이 없고 V1을 보존한 채 되돌릴 수 있다 ② B는 가방에 대한 독립 근거가 없어 지금 투자하면 도박이다 ③ C의 병목은 모델이 아니라 **제품 데이터**(깨끗한 정면 사진, 2종의 3D 모델 부재)다.

## 3. B를 검토하려면 필요한 것

1. 같은 사람 사진 3장 × 제품 8종 × 공급자 2곳으로 **같은 조건 비교**(약 48회 호출, 비용은 `scripts/ai-fitting-ab.mjs`가 호출 전에 표시)
2. 평가 기준(IMAGE-FITTING-IMPROVEMENTS.md의 루브릭)
3. 사진 제공자 동의(실제 사용자 데이터 사용 금지)
