# V5 — 움직임 비교 (V3 / V4 / V5, 같은 추적 데이터)

**방법**: 사용자 손 녹화의 실제 MediaPipe 추적 출력(180프레임)을 정답으로, 화면에 보이는 프레임의 실제 손 위치와 엔진이 그린 가방 위치의 거리를 측정합니다(`tools/motion-study.mjs`, `tools/loss-study.mjs`, 원자료 `data/motion-study.json`, `data/loss-study-v5.json`). 8개 시나리오(천천히/4배/8배 속도 × 감지 주기 15·7.5·5Hz 등)의 평균입니다. 빠른 손은 같은 이동을 시간 압축한 **합성 속도**입니다. **추적 노이즈는 휴대폰의 실제 값을 모르므로** 0·2·4px 가우시안 노이즈를 감지값에 더해 모두 시험했습니다(정답에는 노이즈 없음). 위치 단위는 손바닥 폭(영상에서 약 96px).

**정의**: *가속도 RMS* = 프레임 간 2차 변화(움직임의 거칠기), *진짜 움직임을 뺀 거칠기* = 가속도에서 정답 자체의 가속도(10.1px)를 뺀 값, *순간 최대 점프* = 정답에 없는 프레임 간 이동의 최대값, *방향 전환 직후 오차* = 손이 방향을 바꾼 뒤 150ms 동안의 오차, *정지 손 떨림* = 정지한 손의 가속도 RMS.

**읽는 법과 결론**
1. **칼만 필터는 쓰면 안 됩니다.** 깨끗한 데이터에서는 위치 오차가 0.09~0.13으로 V3의 1/4이지만, 추적 노이즈 2px에서 **정지한 손의 떨림이 3~18px(V3 0.41의 7~43배)**, 4px에서는 20~130px입니다. 칼만이 측정값을 믿는 정도를 노이즈에 맞춰야 하는데 휴대폰의 노이즈를 모릅니다. 노이즈를 온라인으로 추정하는 적응형을 더하면 가능하지만 이번 데이터(정지 영상의 노이즈가 거의 0)로는 검증할 수 없어 **채택하지 않았습니다**(NOT VERIFIED).
2. **감지 시점 필터 + 속도로 잇기**는 오차는 줄지만 가속도 31~35로 V4보다 거칠어 **더 나쁜 교환**입니다.
3. **V4의 선행은 단순히 beta를 올리는 것보다 비효율적**입니다: 같은 평균 오차(0.337 vs 0.333)를 얻으면서 가속도 28.5 vs 21.7, 점프 50 vs 44. (p95만 V4가 약간 낫습니다: 0.630 vs 0.654.)
4. **One Euro의 beta는 "오차 ↔ 거칠기" 한 줄 위의 점**입니다. beta 0.004(14.2) → 0.008(V3, 16.2) → 0.02(21.7) → 0.08(29.5)로 가속도가 올라가는 만큼 오차가 내려갑니다(0.401 → 0.406 → 0.333 → 0.252). **V3보다 오차도 낮고 거칠기도 낮은 점은 이 계열에 없습니다**(가장 가까운 `lead(0.25)`: 오차 −5%, 가속도 −7%이지만 정지 떨림 +6%로 차이가 작아 노이즈 안).
