# V5 — 렌더링 품질: 가림·그림자·소재

**원칙**: 깊이 정보가 없는 상태에서 물리적으로 정확한 가림을 구현한 것처럼 보고하지 않습니다. 아래는 **현재 구현이 실제로 하는 일**과 그 효과의 측정입니다. V5에서 이 영역의 코드는 바꾸지 않았습니다(변경 없음 = 개선 주장 없음).

## 1. 구현 현황과 실제 동작
| 항목 | 구현 | 실제 동작·한계 | 상태 |
|---|---|---|---|
| 손가락 가림 | 손 전체(손바닥+손가락)를 영상 픽셀로 오려 가방 **위에** 덮음 | 손이 가방 앞에 오는 일반적인 쥐는 자세에서는 맞음. 손잡이가 손가락 **사이/뒤**로 지나가는 모습은 못 그림 | PARTIAL |
| 손바닥 가림 | 위와 동일(손바닥 다각형 + 손가락 선) | 같음 | PARTIAL |
| 손 주변 배경 후광 | 사람 분할 마스크와 교차해 배경 픽셀을 제거(V3부터) | 눈으로 비교하면 감소(`images/v3/cmp-daily-tote.png`). **정량 측정은 못 함**: 같은 영상의 서로 다른 실행을 비교하면 프레임의 16.5%가 양쪽(밝게 22,726 / 어둡게 22,296픽셀)으로 변해 마스크 효과를 분리할 수 없었음 | NOT VERIFIED(정량) |
| 팔과 가방의 앞뒤 관계 | **없음** — 항상 손/팔이 앞이거나 가방이 앞 | 깊이가 없어 판단 불가. 팔이 가방 앞을 가로지르는 동작은 틀린 그림이 됨 | **UNSOLVED** |
| 신체와 제품의 깊이 | 가방은 몸 앞 평면에 놓임 | 몸 뒤로 가는 가방은 표현 불가 | **UNSOLVED** |
| 접촉 그림자 | 그림자 전용 투명 평면(가방 바로 뒤)에 그림자 맵 1장, 손 픽셀·가방 픽셀에만 닿는 접촉 음영 | 아래 §2 | PARTIAL |
| 배경과 제품의 분리 | 방 색(4곳 평균)을 조명 색에 일부(50%) 섞고 밝기 보정(조명 이득 0.98) | 색 보정은 VERIFIED(V3). 배경의 조명 방향은 모름(고정 방향) | PARTIAL |
| 소재(광택·반사) | 재질당 거칠기 한 값, 환경 반사 없음 | 원본 광택과 비교할 기준이 없음 | **UNSOLVED** |

## 2. 그림자의 실제 효과 (같은 영상, 그림자 켬 vs 끔, 서로 다른 실행의 프레임)
| 제품 | 변한 픽셀(3단계 초과) | 어두워진 / 밝아진 픽셀 | 평균 변화 | 그 픽셀의 원래 밝기 |
|---|---|---|---|---|
| 밀크팩 이어폰 케이스 | 프레임의 0.86% | 1,903 / 434 | −9.5 단계 | 88/255 |
| 플라노백 | 프레임의 1.85% | 4,935 / 127 | −14.6 단계 | 69/255 |
**해석**: 그림자는 가방 주변 프레임의 1~2%를 원래 밝기의 약 11~21% 어둡게 합니다(이어폰 −9.5/88 ≈ 11%, 플라노 −14.6/69 ≈ 21%). 눈에 띄는 연출이라기보다 **은은한 단서**이고, 배경이 어두울수록(이 영상의 후드티) 절대 변화가 작습니다. 실제 사용자가 "접촉이 자연스러워졌다"고 느끼는지는 **NOT VERIFIED**입니다. 진단 스위치 `&off=shadow`로 끄고 비교할 수 있습니다.
(주의: 켬/끔 프레임은 같은 영상의 서로 다른 시점이라 영상 자체의 미세한 차이가 섞여 있습니다. 이어폰의 "밝아진 434픽셀"이 그 예입니다.)

## 3. 렌더링 성능
헤드리스 소프트웨어 WebGL이라 FPS는 **측정 불가(NOT VERIFIED)**. JS 힙은 V1/V2 103MB → V3/V4/V5 107~118MB(그림자 맵 1장·평면 1개 추가).

## 4. 개선 가능성 (기존 브라우저 기술 범위)
| 방안 | 가능성 | 비용 | 판단 |
|---|---|---|---|
| 배경 밝기에 따라 그림자 농도 자동 조절 | 쉬움 | 낮음 | 효과가 작음, 실기기 확인 후 |
| 포즈 상대 z로 "팔이 가방 앞/뒤" 판정 | 가능하나 정답 데이터가 없어 검증 불가 | 중간 | 영상 요청 후 검토 |
| 단안 깊이 추정 모델 | 가능 | 모델 수십 MB·모바일 부담 | 이번 범위 밖 |
| 손가락이 손잡이를 감싸는 표현 | 손잡이를 손가락 뒤/앞 두 겹으로 나눠 그리기 | 중간(모델마다 작업) | 영상 G 이후 |
