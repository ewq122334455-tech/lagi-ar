# 이미지(사진) 착용 개선

## 상태 요약

| 항목 | 내용 | 상태 |
|---|---|---|
| 사진 사전 점검 | 크기·밝기·선명도·비율을 업로드 직후 검사해 부드러운 안내 표시 (`src/tryon/fitCheck.ts`, `Again.tsx`) | **VERIFIED IMPROVEMENT** (화면 동작) / 오탐률은 NOT VERIFIED |
| 결과 점검 | 원본과 결과를 작은 회색 이미지로 비교해 "잘림·변화 없음·다른 장면" 안내 | **VERIFIED IMPROVEMENT** (화면 동작) / 실제 AI 결과로는 NOT VERIFIED |
| 프롬프트 v2 + 제품 사실 | 옵트인(`#/…?prompt=v2` 또는 Worker `PROMPT_VERSION=v2`). 기본값은 v1 | 구조 시험만 통과 → **NOT VERIFIED** (생성 품질) |
| 유료 A/B 도구 | `scripts/ai-fitting-ab.mjs`, 기본은 예행(dry run) | 구현 완료, **실행하지 않음** |
| 비생성 컷아웃 | MediaPipe 분할 시험 | **적용하지 않음** (ROOT-CAUSE-REPORT P1) |

> AI 사진 결과물의 품질 향상은 **입증되지 않았습니다.** 유료 호출을 하지 않았기 때문입니다.

## 1. 사진 사전 점검
- 기준: 짧은 변 480px 미만, 평균 밝기 <55 또는 >215, 라플라시안 분산 <40(흐림), 가로세로비 >2.4:1
- 동작: 안내만 표시, 업로드를 막지 않음, 자동 재시도 없음
- 시험: 오프라인 단위(정상·어두움·밝음·흐림·작음·극단 비율) + 브라우저 12/12 (fitcheck-ui)
- 한계: 임계값은 합성 이미지로 정했고 실제 사용자 사진 분포로 조정하지 않았음 → 오탐·미탐 **미측정**

## 2. 결과 점검 (`compareResult`)
- 구도 잘림(가로세로비 4% 이상 차이), 거의 동일(변화 <1.2), 다른 장면(같은 구도인데 유사도 <0.55)
- 한계: 제품이 실제로 들려 있는지, 로고가 맞는지는 **판단하지 못함**. 구도·변화량만 본다.

## 3. 프롬프트 v2
v1 대비 추가: 제품이 정확히 1개, 제품 사실(`productFacts`: 형태·치수·손잡이·끈 길이), 착용 방식별 형태(어깨/크로스/손), 인물 보존, 해부학, 제품 글자 보존, 빛과 접촉, 구도 유지.
- 위험: 지시가 길수록 모델이 일부를 무시할 수 있음. 효과 방향은 알 수 없음.
- 롤백: 플래그를 없애면 즉시 v1.

## 4. 평가 루브릭 (A/B 실행 시)
각 1~5점, 두 명 이상 눈으로: ① 제품 형태 충실도 ② 로고·글자 ③ 색 ④ 크기 비례 ⑤ 손·몸과의 접촉 ⑥ 그림자·조명 ⑦ 인물 보존(얼굴·체형 왜곡 없음) ⑧ 구도 유지 ⑨ 실패율. 샘플: 사람 사진 3장 × 제품 8종 × v1/v2 = 48장.

## 5. 승인이 필요한 일
`LAGI_AB_CONFIRM_PAID=yes`와 `--yes`를 둘 다 주어야만 실행됩니다. 비용 추정치를 먼저 출력합니다. **사용자 동의를 받은 인물 사진**이 있어야 합니다.
