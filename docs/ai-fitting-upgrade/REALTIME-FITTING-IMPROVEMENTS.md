## 변경 (`src/v3/fitFilter.ts`, `MapTryOn.tsx`)
1. **One Euro 필터**(시간 기반): 프레임 속도에 상관없이 같은 느낌. 위치 (2.0, 0.008), 크기 (0.8, 0.002), 각도 (1.5, 0.8)
2. **점프 거부**: 손 이동이 손바닥 폭의 2.5배를 넘는 검출은 그 프레임에서 무시
3. **유실 시 유지**: 손이 사라진 뒤 350ms는 마지막 위치로 계속 그림 (V1은 즉시 다른 경로로 전환)

## 시도했다가 버린 것
- 위치 필터 minCutoff 1.2 / beta 0.012 → 팬에서 가속도가 V1보다 악화
- 이전 속도로 앞질러 예측(carry-forward) → 가속도 2배. 삭제
- 파라미터 스윕(`sweep.json`): V1을 모든 지표에서 이기는 설정이 없었음. 중립값 선택
